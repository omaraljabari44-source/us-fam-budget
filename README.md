# US FAM BUDGET

A mobile-friendly family budgeting dashboard.

## Current version
- Family PIN login
- Add expenses with amount, category, note, and date
- Food, Entertainment, Rent, Purchases, and Other categories
- Family total, personal total, and entry count
- Category filtering
- Users can delete their own entries

## Important
The current starter uses browser `localStorage`, so data does not yet sync between devices. The next phase is to connect real authentication and a hosted database before using it for private family financial information.
